# 星笺/Staria

这是一款轻量化、简约风的笔记软件，集成日记、摘抄、随笔三个功能，满足日常所需的大部分记录需求。

## UI界面

全局背景采用白色。

### 首页

- 首页采用极简风格设计，中间靠上位置以较大字体居中展示“星笺”sloganz，字体使用"D:\Edge\AaGuDianKeBenSongYouMoBan\AaGuDianKeBenSongYouMoBan\GuDianKeBenSong.ttf"，后续需要使用此字体时统一称刻本宋体，未作要求则统一使用系统默认字体。
- 中间靠下位置以卡片形式展示“纸条”功能摘录的句子，滑动或点击展示下一张，堆叠展示卡片，上限为五张，纸条数量小于五时按实际数量现实，设计方案参考 /leibox skill 内的拖甩照片卡片。
- 左上方为圆形个人主页按键，头像为昵称首字符。
- 最下方为页面底栏与新建按钮，并排展示，页面底栏为长条胶囊形状，新建按钮为圆形，收起在页面底栏右侧。点击新建按钮，按钮向上展开，上下排列为三个圆形按钮。
- 页面底栏展开时可以切换当前页面。页面底栏包含以下按钮：首页，时间，纸条，思索。
    - 底栏内的按键使用“图标＋文字”的组合。图标均使用黑色线条构成的简约标志。
    - 时间一栏使用沙漏图标，纸条一栏使用堆叠展开的纸条图标，思索使用羽毛笔图标。按键文字均位于图标下方。
- 新建按钮展开时可以点击对应按键拉起编辑页面。新建底栏包含以下按钮：日记，摘录，随笔。

### 个人主页

- 唤起时从左侧滑出，占屏幕左侧四分之三宽度，右侧四分之一为当前首页并压暗，点击该区域收起个人主页。
- 主页左上方为昵称，点击弹出浮窗修改。浮窗包含取消与确定两个选项。昵称的字数不大于8个汉字，3个英文或数字字符视为一个汉字。
- 昵称下方为记录数量卡片，由上至下三行，按以下格式分别展示时间、纸条、思索的数量。以下展示出的三个标题使用刻本宋体，后续实际数量使用系统字体。

```
时间：- 条
纸条：- 张
思索：- 篇
```

- 再下方两行分别为星尘（即回收站）和设置入口。

### 时间（日记查看页）

- 左侧为竖向时间轴。
    - 时间轴的形态为一根竖线，对齐左下角页面按键的中心。时间轴上具体日期处会显示一个圆点将时间轴截断，节点右侧显示日期。
    - 时间轴加日期，显示范围不超过屏幕左侧1/4 。
    - 时间轴靠下为最新日期。
    - 长按时间轴任何日期超过一秒，唤起日历卡片，选择对应日期快速跳转。日历卡片左上角的标题为刻本宋体。
- 时间轴右侧分行展示对应日期的日记标题，每篇一行。点击该行展开为卡片展示，背景压暗。日记卡片右上角为编辑和删除按钮。
- 点击编辑，唤起编辑页面。点击删除，将该条移入回收站，此页不再展示（其余功能删除的内容也按此方式处理）。首次点击删除时，弹窗进行确认，并提供不再展示选项，未勾选则下次还会展示。
- 操作（点击、滑动）该页面时，若底栏展开，则自动收起。

### 纸条（摘录查看页）

- 以等宽的卡片上下排列展示纸条摘录，卡片颜色略微深于背景白色，但不得影响文字阅读。
- 卡片的第一行为最近编辑日期（精确至日）。新的卡片展示在下方。
- 长按卡片超过一秒弹出选择编辑、删除、多选的tooltip。
- 多选时所有卡片第一行日期右移，日期左侧显示选中框。多选模式下，右下角新建按钮变为红色的删除按钮，点击进行批量删除。
- 第二行开始展示卡片正文。
- 若摘录时写明出处，则在卡片右下角展示，且出处文字前添加破折号。
- 留空时显示与时间页面相同格式的“paper”slogan。

### 思索（随笔查看页）

- 以等宽的卡片上下排列展示随笔预览。第一行为日期。
- 第二行以更高字号和字重展示标题。
- 第三行展示正文预览，行末显示不下的用省略号替代。
- 点击卡片，进入查看页面，为二级全屏页面。
    - 左上角为圆形返回按键，右上角为圆形更多选项按键，点击按键展开tooltip菜单，选择编辑或者删除。
    页面的标题行显示：“随笔：＋标题实际内容”，前半段固定内容用刻本宋体显示。
- 长按卡片，展开tooltip菜单，逻辑与时间和纸条页相同。
- 该页为空时，展示“think”slogan。

### 编辑页

- 三种类型（日记、摘录、随笔）编辑页格式相同。
- 页面左上角为退出按键。退出时内容做修改未保存，弹窗询问是否保存。
- 页面右上角为保存按钮。圆形，使用icon。
- 保存按钮左侧以高度相同的胶囊显示撤回与重做的icon按钮。
- 按钮与胶囊均可以悬浮在内容上，滑动页面时标题与正文内容整体滑动。
- 第一行左侧用刻本宋体显示当前编辑类型（日记、摘录、随笔）。
    - 若当前编辑的为日记或者随笔，则该行右侧为标题编辑区域。
    - 若为摘录，则显示“from”，右侧编辑摘录来源。
    - 长按该处类型显示文本，弹出tooltip，可以切换当前的编辑类型。
- 第一行与正文编辑区域之间以日期分割。此处日期与查看页面的日期统一，日记和摘录保持创建该条时的日期，随笔保存最近一次保存编辑的日期。
- 日记和摘录编辑为普通文本格式输入，随笔支持markdown格式编辑。
- 随笔编辑markdown文本时，实时切换为预览格式。如：输入#号并空格，当前该行输入文字立刻加大加重，且隐藏前面的格式代码。

### 星尘页

这个页面的实际作用为回收站，在个人主页点击后进入二级页面。

- 左上角为返回按键。右侧刻本宋体显示“星尘”标题。
- 所有条目均以等宽等高的卡片展示，默认新删除的在上方。
- 卡片第一行为：“当前内容类型 + 日期”。第二行为正文预览，仅显示一行，行末显示不下的用省略号。
- 长按卡片一秒，弹出tooltip弹窗，包含恢复、删除、多选三个选项。
    - 删除后永久删除，不再保留。
    - 恢复后移出星尘页，回到对应查看页。
    - 多选后进入多选模式，所有卡片的第一行左移，左侧显示选中框。此时左下角显示恢复按钮，点击批量恢复。右下角为删除按钮，点击批量删除。批量操作前均弹窗提示是否确认。

### 设置页

目前设置页的功能仅展示交互按键，不添加实际功能。后续会添加新的设置项。

- 左上方为返回按键。右侧刻本宋体显示“设置”标题。
- 第一行为主题色选择卡片，格式参考：
```
当前：颜色名

[颜色预览]  [颜色预览]  [颜色预览]  [颜色预览]
```
- 目前暂定八种颜色，分两行预览。
    - 初始默认的简约白、 #7BA7D9 迷雾蓝、 #8FB8C9 月白青、 #ED656A 山茶红、 #F8BC31 熟杏黄、 #40A070 浅葱绿、 #F596AA 樱花粉、 #B481BB 红藤紫
- 第二行为深色模式开关。右侧显示当前模式，点击向下打开tooltip，可选择：跟随系统、打开、关闭。默认为跟随系统
