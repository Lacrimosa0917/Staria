# 星笺·Staria

**欢迎来到星笺。**

这是一个集成了日记、摘录、随笔三个功能的轻量化创作软件，你可以在这里记录你的所思所想。

本软件持续更新，如果你觉得好用，或者期待新的功能，可以点一个star。

## 作者的碎碎念

我是一个很懒，但又喜欢创作的人。

我用过好几个日记软件，但是都不太符合我这个极简主义者的路数，于是放弃。我理想中的日记软件，应该有一个板块写我的见闻与情绪，一个板块写我读到的好句，一个板块写我的思考与想法，除此之外，就不需要太多功能了。

这就是这个软件三个功能的来历：**时间，纸条，思索**。

总之AI确实好用，因为这是个vibecoding率大概百分之百的软件。由于主要基于我个人的需求，所以只制作了Android版本，后续也没有更新iOS版本的打算。不过如果你需要，可以下载源码，按自己的需要适配即可。

> 本项目使用GPL v3许可，支持二开，禁止商用。

## 功能

> 思索的页面里预置了一篇说明书，如果有需要，可以查看。

### 首页

这里展示你摘录的句子，点击或滑动卡片切换下一张。

### 时间

这里会按时间线排列你的日记，点击标题展开正文，长按标题查看更多操作。

长按左侧日期，可以展开一个日历快速跳转，不过没有写日记的日期是不能跳转的。

### 纸条

这里完整排列你的摘录，新加入的句子会立刻进入首页的卡池。

点击卡片展开，长按卡片查看更多操作。

### 思索

这里排列你写的随笔，点击进入查看页，长按显示更多操作。

### 编辑页

点击右下角的新建，会弹出三个按钮，由上至下依次是：日记、摘录、随笔。编辑页下，也可以长按标题旁边那个标签，快捷切换编辑的类型。

随笔的编辑支持基础的markdown格式（目前仅实现首行标题，其余语法如加粗、斜体、引用、列表等后续会根据需求决定是否适配）。

### 个人主页

在主页点击左上角的头像，进入个人主页。

可以编辑昵称，首字符会作为主页头像。

星尘，即回收站，主页删除的内容会暂时保留在这里。你可以恢复，也可以彻底删除。

设置，你可以在这里设置软件，不过目前的功能还只有切换主题色和深色模式。

## 安装方法与系统要求

点击右侧的`Releases`，找到最新版的apk包，下载安装即可。

后续会添加在app内更新版本的功能，目前只支持手动下载更新。

支持 Android 8.0（API 26）及以上版本。

> 实际测试使用：Android 16 模拟器、Android 17 实机

---

## 从源码构建

如果你想自己添加新的功能，需要 JDK 17 与 Android SDK（compileSdk 37）。

git clone <repo>
cd Staria
./gradlew assembleDebug
